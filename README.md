# SSH Tunnel Manager

Simple WinForms Local Port Forwarding manager for .NET. Allows you to easily turn on/off tunnels to hosts located behind another SSH server.

Requirements:

 - An SSH server that you can access with your SSH key. Password auth is not supported. The server should sit between you and the resource you want to connect to.
 - Your SSH key loaded into Pagent (or a Pagent-compatible program)
